# PesaChain project-local Claude skills

| Skill | Use when |
|---|---|
| `pesachain-orchestrator` | Building the complete system or planning multiple implementation phases |
| `pesachain-backend` | Working on Spring Boot, PostgreSQL, RBAC, applications, loans, repayments, or outbox records |
| `pesachain-blockchain` | Working on Solidity, event recording, RPC integration, retries, or verification |
| `pesachain-design` | Refining frontend architecture, UI/UX, responsive layouts, motion, gradients, or accessibility |
| `pesachain-playwright` | Creating or running end-to-end browser tests |

These skills are authoritative for PesaChain-specific behavior. Optional third-party skills augment
them only when they are genuinely installed and do not conflict with `CLAUDE.md`.
