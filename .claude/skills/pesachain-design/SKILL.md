# PesaChain design

1. Read `docs/claude/03-UI-UX.md`.
2. Inspect the current prototype and preserve its information architecture.
3. Check whether optional `ui-ux-pro-max`, awesome-design/frontend-design, 21st.dev, and motion
   capabilities are installed; use only capabilities actually available.
4. Build/refine local reusable components and semantic tokens before adding one-off styling.
5. Use restrained gradients and purposeful reduced-motion-safe animation.
6. Implement loading, empty, validation, error, forbidden, not-found, and success states.
7. Test desktop, tablet, mobile, keyboard, focus, contrast, and 200% zoom.
8. Keep operational and blockchain states visibly separate.
