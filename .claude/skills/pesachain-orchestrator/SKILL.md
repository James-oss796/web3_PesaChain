# PesaChain orchestrator

1. Read `CLAUDE.md` and every file in `docs/claude/` in numbered order.
2. Inspect repository status, current code, scripts, and installed capabilities.
3. Create or update `docs/DECISIONS.md` and `docs/IMPLEMENTATION_STATUS.md`.
4. Follow the phase sequence in `docs/claude/00-EXECUTION-PLAN.md`.
5. Load the project-local backend, blockchain, design, and Playwright skills only when entering
   those phases.
6. Deliver one tested vertical slice at a time.
7. Stop a phase if its exit gate fails; diagnose and repair it before broadening scope.
8. Preserve the product boundaries in `CLAUDE.md`.
9. End each work session with completed changes, verification evidence, remaining checklist items,
   and blockers.
